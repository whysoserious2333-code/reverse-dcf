# 反推 DCF · 预期翻译器（Reverse DCF Expectations Calculator）

把市场报价（市值）反推成它隐含的增长预期。

**不是估值、不是目标价、不是投资建议**——只回答一个问题：以今天的价格买入，市场默认了什么样的增长。所有默认值（含自动拉取的财报）都只是一个起点，每个输入都可手动覆盖；结论完全取决于你喂进去的输入。

## 它做什么

给定市值与基本面，用 `brentq` 反解出：在指定 WACC、显性期、终值方法下，能让模型企业价值（EV）等于市场报价 EV 所需的隐含增长率。换句话说，它把价格翻译成"市场隐含的假设"，而不是独立给一个价。

## 两种模式

- **从 FCFF 出发**：适合已盈利 / 正现金流公司。头条为隐含 FCFF CAGR。
- **从收入出发**：适合当前 FCFF 为负 / 盈利前公司。让 FCFF 利润率从当前（可为负）沿路径收敛到一个**你假设的**稳态正利润率，反解隐含收入 CAGR，并报出 FCFF 预计转正的年份。注意：稳态利润率是全模型最敏感、最主观的输入，界面会显著提示并给出敏感性。

## 基年口径（自动拉取时三选一）

按公司性质自己选——差异本身就是信息：

- **TTM（最近 4 季滚动，默认 / 推荐）**：避免年报滞后。财年早结束、或基本面快速变化时（如周期上行），最新一个完整财年可能已严重过时。
- **指定财年**：看单个会计年度。
- **近 5 年均值（周期）**：周期股的中性起点，避免用周期顶或谷当基年。

经验法则：强周期股不要用单一峰值年；TTM 反映当下但可能正处周期高位；均值更中性。三个都看一眼再下判断。

## 内置方法论约定

- 10 年显性期 FCFF 折现
- 双终值：永续增长 Gordon（默认 g = 2.5%）/ Exit Multiple（可套终值年 FCFF、EBITDA 或收入 EV/Sales）
- WACC 由 CAPM 构建，含美 / 日 / 韩口径预设；β 使用 **Damodaran 行业 β（手填）**——界面会显示数据商的个股回归 β，但仅作 sensitivity 参照，不默认采用
- FCFF 由**原始行项透明计算**（CFO − Capex，可选税后利息加回转 FCFF 口径），**不使用数据商预算好的 FCF / DCF 成品数**
- SBC：免费数据源的现金流表不含 SBC 行；需要 SBC 负担口径时手动填，从基年扣除
- 自动告警：终值现值占比 > 75%（结论高度依赖终值）、FCFF 在正负间波动（疑似周期 / 转折期）

## 数据源与已知边界

自动拉取使用 **Alpha Vantage 免费档**，采用**自带 key（bring-your-own-key）**——每位用户填自己的免费 key，额度算自己的，公开使用不受单一额度限制。

边界：

- **仅美股**。非美标的请用手动模式，并核对市值与财报币种是否一致。
- **无 SBC 行**（数据源限制），需手填。
- **市值为快照**（最近交易日收盘价 × 股数，带日期）。市值变化快——**发布前务必用你自己的可核验来源重新核对**，自动值仅作占位。
- 免费档约 **25 次 / 天**，每只票约 4–5 次调用（≈ 5 只 / 天），单次拉取约 5–6 秒（受每秒 1 次限速，已自动放慢 + 退避重试）。
